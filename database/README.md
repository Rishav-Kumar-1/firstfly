# TravelGo Database

This folder contains all MySQL database files.

## Files

| File | Purpose |
|------|---------|
| `schema.sql` | Creates all tables and relationships |
| `seed.sql` | Inserts demo/sample data |

## Setup Instructions

1. Install MySQL (if not already installed)
2. Open MySQL Workbench or MySQL command line
3. Run `schema.sql` first to create the database and tables
4. Run `seed.sql` to insert demo data

```
travelgo
```
